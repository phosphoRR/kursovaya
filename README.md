# Курсовая работа — перевод дробных чисел

Тема: клиент-серверное приложение «Перевод дробных чисел из одной системы счисления в другую» на C# с REST API.

## Текущий этап: прототип серверной части

Реализованы:
- ASP.NET Core Minimal API;
- маршрут `GET /health` для проверки работы сервера;
- маршрут `POST /api/convert` для перевода чисел между основаниями 2–16;
- проверка входных данных и ограничение точности 0–10 знаков;
- математическое ядро с точными рациональными вычислениями на `BigInteger`;
- автоматическая сборка в GitHub Actions.

**Пока не реализованы:** регистрация, JWT, SQLite, история, консольный клиент, экспорт и тесты. `/api/convert` на этом этапе не защищён авторизацией. Это учебный прототип, а не готовая курсовая.

## Локальный запуск (Ubuntu, .NET 8 SDK)

```bash
dotnet run --project src/FractionConverter.Server
```

Сервер покажет адрес в терминале. Пример запроса (замените порт адресом из терминала):

```bash
curl -X POST http://localhost:5000/api/convert \
  -H 'Content-Type: application/json' \
  -d '{"number":"10.75","sourceBase":10,"targetBase":2,"precision":10}'
```

Ожидаемый результат: `{"result":"1010.11"}`.

## Как работает перевод

Входное число читается как точная рациональная дробь `числитель / знаменатель`. Целая часть переводится последовательным делением на новое основание, дробная — последовательным умножением на него. Выдаётся **не более** указанного количества дробных цифр, методом отсечения; конечные нули дробной части не дописываются. Для периодических дробей это приближение. Правило округления следует согласовать с преподавателем.

## Что показать преподавателю

Откройте `src/FractionConverter.Server/Program.cs`, `src/FractionConverter.Server/NumberConverter.cs` и вкладку Actions. В Actions проверяется компиляция, но не функциональная корректность приложения.

Следующие шаги: NUnit-тесты, регистрация и авторизация, SQLite и персональная история, консольный клиент, документация.

Техническое задание и официальное задание хранятся у студента отдельно. Репозиторий не должен содержать пароли, токены и рабочую базу пользователей.
